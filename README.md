## نبذة عن الأداة

Locution هي أداة قوية مكتوبة بلغة البايثون تمكنك من تحديد الموقع الحقيقي لأي رقم هاتف. تقوم الأداة بتحليل رقم الهاتف واستخراج معلومات مفصلة عنه مثل الدولة، مزود الخدمة، والموقع الجغرافي.

**المطور**: SayerLinux  
**البريد الإلكتروني**: SaudiSayer@gmail.com

## المميزات

- تحديد الموقع الجغرافي لرقم الهاتف
- عرض معلومات مفصلة عن مزود الخدمة
- عرض المنطقة الزمنية للرقم
- توفير رابط مباشر لموقع الرقم على خرائط جوجل
- وضع التتبع المستمر (لايف) لمراقبة الموقع في الوقت الحقيقي
- عرض معلومات إضافية مثل دقة الموقع وحالة الاتصال
- واجهة سهلة الاستخدام مع ألوان جذابة

## متطلبات النظام

- نظام تشغيل لينكس
- بايثون 3.6 أو أحدث
- المكتبات المطلوبة (يتم تثبيتها تلقائياً باستخدام الأمر أدناه)

## التثبيت

1. قم بتنزيل المستودع:

```bash
git clone https://github.com/SayerLinux/Locution.git
cd Locution
```

2. قم بتثبيت المكتبات المطلوبة:

```bash
pip install -r requirements.txt
```

3. قم بمنح صلاحيات التنفيذ للسكربت:

```bash
chmod +x locution.py
```

## طريقة الاستخدام

### استخدام الأداة مباشرة:

```bash
./locution.py
```

سيطلب منك البرنامج إدخال رقم الهاتف بالصيغة الدولية.

### استخدام الأداة مع تحديد رقم الهاتف مباشرة:

```bash
./locution.py -n +966501234567
```

### استخدام وضع التتبع المستمر (لايف):

```bash
./locution.py -n +966501234567 -l
```

هذا الوضع يقوم بتحديث معلومات الموقع كل 5 ثوانٍ، مما يتيح لك مراقبة الموقع في الوقت الحقيقي. اضغط Ctrl+C للخروج من هذا الوضع.

### عرض المساعدة:

```bash
./locution.py -h
```

## ملاحظات هامة

- يجب إدخال رقم الهاتف بالصيغة الدولية (مثال: +966501234567)
- الأداة تعمل فقط على نظام لينكس
- استخدم الأداة بمسؤولية وفقط للأغراض القانونية
